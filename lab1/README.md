# Лабораторная работа 1 — вариант 13

Консольная программа на C++20 для работы с динамическими C-строками (`char*`).

## Структура

```text
lab1_variant13/
├── CMakeLists.txt
├── include/
│   └── str_ops.h
├── src/
│   ├── main.cpp
│   └── str_ops.cpp
└── tests/
    ├── CMakeLists.txt
    └── test_variant.cpp
```

## Реализованные функции

- `str_alloc` — копирует строку в новую динамическую память;
- `str_len` — вычисляет длину до `\0`;
- `str_copy` — копирует строку в существующий буфер достаточного размера;
- `str_delete` — освобождает память и обнуляет указатель;
- `str_print` — печатает строку;
- `str_substr` — создаёт динамическую копию подстроки;
- `str_compare` — лексикографически сравнивает две строки.

`nullptr` безопасно трактуется как пустая строка. Результат `str_substr` всегда нужно освободить через `str_delete`.

## Visual Studio

1. Выберите **Файл → Открыть → Папка**.
2. Откройте корневую папку `lab1_variant13`, в которой лежит `CMakeLists.txt`.
3. Дождитесь окончания настройки CMake.
4. Выберите целью запуска `lab1_variant13.exe`.
5. Запустите программу сочетанием `Ctrl+F5`.
6. Для тестов выберите **Тест → Обозреватель тестов → Запустить все**.

При первой настройке CMake потребуется интернет: Google Test загружается автоматически.

## Сборка из PowerShell

Находясь в корне проекта:

```powershell
cmake -S . -B build
cmake --build build
ctest --test-dir build --output-on-failure
```

Для одноконфигурационной сборки (например, Ninja) запуск:

```powershell
.\build\lab1_variant13.exe
```

Для генератора Visual Studio запуск обычно выглядит так:

```powershell
.\build\Debug\lab1_variant13.exe
```
